# Готую сам

Помічник на кухні для людини, яка тільки вчиться готувати. Він складає здорове меню
«напівдієта» на тиждень під ваш графік роботи і показує рецепти за рівнями складності.
Ще він збирає список покупок. Підказки готовності тут не спираються на колір, тому додатком
зручно користуватися з порушенням кольоросприйняття.

## Що вміє

- **Рецепти за рівнями складності.** 55 рецептів українською.
  - **Рівень 1 · Просто** (28 рецептів): мікрохвильовка, аерогриль, яєчня на сковороді, зварити гречку чи макарони, страви без готування.
  - **Рівень 2 · Середньо** (18 рецептів): сковорода й каструля, 2–3 складники, котлети, тушкування, супи.
  - **Рівень 3 · Складно** (9 рецептів): духовка й плита разом, кілька етапів. Серед них борщ, голубці, фаршировані перці, лазанья з кабачків.
- **Персональна норма.** Рахується за формулою Міффліна — Сан Жеора і враховує стать, вік, зріст, вагу, тип роботи (сидяча, на ногах, фізична, важка) і тренування. Режим «Схуднути м’яко» знімає 15 % від денних витрат, але не опускає норму нижче базового обміну. Білки, жири, вуглеводи, клітковина, вода, а також овочі й фрукти (≥ 400 г) рахуються окремо.
- **Прийоми їжі під графік.** Додаток знає робочі дні, години роботи й дорогу. Він враховує денну, вечірню і нічну зміну та роботу з дому. Те, що припадає на робочий час, позначено «З собою»: такі страви можна взяти в контейнері. Якщо на роботі немає мікрохвильовки, пропонуються лише страви, які смачні холодними.
- **Меню на тиждень.** Порції підлаштовуються під калорії кожного прийому. Меню стежить за різноманітністю, пропонує рибу двічі на тиждень і білок близько норми. У будні частіше трапляються прості страви, на вихідних складніші. Будь-яку страву можна замінити одним дотиком.
- **Готування із запасом.** Вечерю можна приготувати на 2 порції, і друга стає обідом наступного дня. Нагадування «що підготувати» підказують, коли залити вівсянку з вечора, коли розморозити рибу і що взяти з собою.
- **Список покупок.** Продукти розкладені за відділами магазину, кількості округлені вгору до зручних покупок («7 яєць», «1,3 кг»). Список можна скласти на весь тиждень або окремо на Пн–Ср і Чт–Нд. Покупки відмічаються позначками, готовий список копіюється в месенджер.
- **Режим «крок за кроком».** Великий шрифт, кілька таймерів одночасно зі звуком і вібрацією. Екран не гасне, поки ви готуєте.

## Дружній до людей з порушенням кольоросприйняття

- У рецептах немає «до золотистої скоринки» чи «доки не перестане бути рожевим». Готовність визначається **термометром** (курка 74 °C, фарш 71 °C, риба 63 °C), **часом** (таймер у кожному кроці), **текстурою, звуком і запахом**. Тест `tests/data.test.ts` автоматично блокує рецепти з такими словами.
- Кожен рецепт із сирим м’ясом чи рибою має крок із перевіркою термометром. Це теж перевіряє тест.
- В інтерфейсі колір ніколи не єдиний сигнал:
  - рівні показуються **стовпчиками** (▮▯▯ / ▮▮▯ / ▮▮▮) разом із текстом;
  - вибрані елементи мають позначку ✓;
  - перевищення норми заштриховане і підписане «▲ на 120 ккал більше»;
  - сьогоднішній день позначений пунктиром і крапкою;
  - різні типи підказок відрізняються іконками й типом рамки.
- Палітра — кобальтовий синій і жовтогарячий з палітри Окабе — Іто, без пар «червоний / зелений». Текст контрастний: рівень WCAG AA для всього тексту, AAA для основного. Є розмір шрифту «великий» і «дуже великий», світла й темна теми.

## Як користуватися на телефоні

Найпростіший спосіб — опублікувати додаток через GitHub Pages. Це безкоштовно, і репозиторій уже підготовлений:

1. Злийте гілку в `main`.
2. На GitHub відкрийте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Після кожного пушу в `main` workflow `.github/workflows/deploy.yml` перевіряє тести, збирає сайт і публікує його за адресою `https://<ваш-логін>.github.io/kitchen-/`.
4. Відкрийте адресу на телефоні й натисніть «Додати на головний екран». Додаток запускатиметься як звичайна програма і працюватиме офлайн.

Усі дані (профіль, меню, позначки) зберігаються **лише на вашому пристрої** (`localStorage`) і нікуди не надсилаються. Щоб перенести дані на інший телефон, скористайтеся розділом «Профіль → Резервна копія».

## Розробка

```bash
npm install
npm run dev          # локальний сервер розробки
npm test             # 400+ тестів: дані рецептів, норма, розклад, меню, покупки
npm run build        # перевірка типів + збірка в dist/ (PWA з офлайн-режимом)
npm run build:artifact  # версія для перегляду на claude.ai (React з cdnjs)
```

Додаткові звіти:

```bash
REPORT=1 npx vitest run tests/report.test.ts   # калорії/БЖВ кожного рецепта
SIM=1 npx vitest run tests/sim.test.ts         # меню для різних профілів (зміни, обмеження)
```

### Структура

```
src/
  data/
    products.ts        продукти: КБЖВ на 100 г, вага штуки, форми слова, відділ магазину
    recipes/level1-3   рецепти за рівнями
    types.ts           типи даних (крок: текст, таймер, ознака готовності, температура, застереження)
  logic/
    targets.ts         норма калорій і БЖВ (Міффлін — Сан Жеор + коефіцієнт активності)
    schedule.ts        час прийомів їжі під денну/вечірню/нічну зміну
    planner.ts         генератор меню, заміна страв, залишки на обід
    shopping.ts        список покупок
    format.ts          українські відмінки й кількості («2 яйця», «½ цибулини», «1 ст. л.»)
    colorWords.ts      заборонені «кольорові» ознаки готовності
  ui/                  екрани React: Меню, Рецепти, Рецепт + режим готування, Покупки, Поради, Профіль
tests/                 Vitest
docs/RESEARCH.md       що знайшли в мережі і як це вплинуло на додаток
```

### Як додати рецепт

Додайте об’єкт у `src/data/recipes/levelN.ts` і використовуйте `id` продуктів із `products.ts`. Кількості вказуються в грамах на весь рецепт. Кроки з очікуванням отримують `timer` (у секундах), а ознаку готовності без кольору — у полі `done`. Для сирого м’яса чи риби обов’язковий `temp`. Тести підкажуть, якщо щось пропущено.

## Застереження

Додаток не замінює консультацію лікаря чи дієтолога. Якщо у вас діабет, хвороби нирок чи серця або ви вагітні, узгодьте раціон зі спеціалістом.
